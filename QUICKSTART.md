# Быстрый старт за 1 минуту (PageSpeed Metrics Toolkit)

> [!NOTE]
> 💡 **Нужна ли регистрация или API-ключ? НЕТ, абсолютно не нужна!**  
> Программа работает сразу «из коробки» без регистрации, без аккаунтов Google и без ввода ключей через встроенный локальный движок.

## ⚡ Экспресс-запуск на любом ПК

### Шаг 0. Требование
* Убедитесь, что установлен **[Node.js](https://nodejs.org/)** (версия 18+ LTS).  
* Если его нет, скачайте установщик с официального сайта: **https://nodejs.org/**.

### Шаг 1. Получить проект
```bash
git clone https://github.com/ykr0p/PageSpeed_Insights_audit.git
cd PageSpeed_Insights_audit
```
*(Или скачайте архивом ZIP с GitHub и распакуйте в любую папку).*

### Шаг 2. Запустить в один клик
* **На Windows:** дважды кликните по файлу **`run.bat`**.
* **На macOS / Linux:** выполните `./run.sh`.
* Софт проведет самодиагностику системы, определит браузер (Chrome или встроенный Microsoft Edge) и запросит адрес.

### Шаг 3. Ввести адрес
* Введите URL (например, `https://vstu.by/ru` или `https://workdo.ru`).
* Нажмите **Enter** (выберется рекомендуемый локальный режим `[1]`, который работает везде и не имеет лимитов).
* Готовый интерактивный HTML-дашборд откроется в браузере автоматически!

> 💡 **Для работы офлайн / на парах без интернета:**  
> Запустите один раз **`setup.bat`** (или `./setup.sh`), он скачает локальные компоненты Lighthouse, и программа будет работать полностью автономно.

## 🛠️ Запуск через командную строку (CLI)
```bash
node bin/psi-audit.mjs --url https://vash-sait.ru
```

### Сразу открыть красивый интерактивный отчет в браузере:
```bash
node bin/psi-audit.mjs --url https://vash-sait.ru --open
```

### Проверить только мобильную версию:
```bash
node bin/psi-audit.mjs --url https://vash-sait.ru --device mobile
```

### Проверить и мобильную, и десктопную версии:
```bash
node bin/psi-audit.mjs --url https://vash-sait.ru --device both
```

## 4. Где смотреть отчеты?

Все отчеты автоматически сохраняются в папку:
```text
F:\Download\TPO\metrics\reports\
```
- `latest-report.html` — последний сгенерированный визуальный дашборд.
- `audit_<сайт>_<дата>.html` — архивные детальные отчеты.
- `audit_<сайт>_<дата>.md` — отчет в формате Markdown для документации и баг-трекеров.
- `demo-workdo-report.html` — готовый пример эталонного отчета.
